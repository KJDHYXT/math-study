# 数学学硕备考 · 学习与复习功能专区

> 基于 **规范驱动开发（Specification-Driven Development, SDD）** 构建的前后端分离网页系统。

## 一、系统定位

本系统服务对象为**备考数学学硕（数学分析、高等代数/线性代数）** 的学生，提供一套单用户、可跨设备访问的**学习与复习**工作台，覆盖以下核心能力：

| 能力 | 说明 |
| --- | --- |
| 笔记管理 | 以 Markdown + LaTeX 编写、分类、检索数学笔记 |
| 题库与刷题 | 录入题目与答案，按知识点组卷刷题，维护错题本 |
| 知识点图谱 | 维护知识点及其依赖关系，可视化学习脉络 |
| 知识检索 | 对笔记、题目、卡片、知识点做全文检索 |
| 记忆卡片 / 间隔重复 | 制作问答卡片，按遗忘曲线（SM-2 类算法）安排复习 |

## 二、SDD 工作流（本项目的开发方法）

SDD 将**规范文档**作为实现与验收的唯一依据，流程如下：

```
需求分析 -> 规格说明 -> 数据模型 -> 架构设计 -> 接口契约
        -> 界面/路由规范 -> 任务分解(依赖图) -> 迭代实现
        -> 测试与验收 -> (回到需求，闭环)
```

每一步产出的文档都会被**编号、版本化**，后续实现与测试均引用这些编号，保证"文档即规范、规范即验收标准"。

## 四、目录结构

```
analysis/
├── docs/            # 本规范文档体系（唯一权威来源）
├── backend/         # FastAPI 后端（Python 3.11+）
│   ├── app/
│   │   ├── main.py          # 应用入口
│   │   ├── models/          # SQLAlchemy 数据模型（对应文档 02）
│   │   ├── schemas/         # Pydantic 请求/响应契约（对应文档 04）
│   │   ├── routers/         # 路由（对应文档 04）
│   │   ├── services/        # 业务逻辑（含 SM-2 算法、全文检索）
│   │   └── core/            # 配置、鉴权、异常处理
│   ├── tests/               # pytest 测试（对应文档 07）
│   └── requirements.txt
└── frontend/        # Vue3 + TS + Vite 前端
    ├── src/
    │   ├── api/             # API 客户端（对应文档 04）
    │   ├── views/           # 页面（对应文档 05）
    │   ├── components/      # 组件
    │   ├── stores/          # Pinia 状态
    │   ├── router/          # 路由（对应文档 05）
    │   └── utils/           # KaTeX 公式渲染、工具
    └── package.json
```
