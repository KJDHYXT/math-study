# 01 · 需求规范（SRS）

> 版本：v1.0 ｜ 更新：2024-XX-XX ｜ 作者：学生（AI 协作）
> 对应文档：00-SDD流程；下游：02 数据模型、03 架构、04 接口、05 界面

---

## 1. 产品愿景

为备考**数学学硕（数学分析、高等代数/线性代数）** 的学生提供一套**单用户、可跨设备访问**的学习与复习工作台。它把笔记、题目、卡片、知识点统一到一处，遵循科学的记忆规律（间隔重复），帮助用户高效备考。

## 2. 用户与场景

**目标用户**：医学硕士备考学生（即用户本人）。单用户，无需多角色。

**典型场景**：
1. 上课/看书后，把定理、推导整理成**笔记**（含公式）。
2. 把某章重点做成**记忆卡片**，每天按计划**复习**。
3. 把历年题或习题录成**题目**，按知识点**刷题**，错的记入**错题本**。
4. 用**知识点图谱**梳理数学分析的章节依赖，形成整体脉络。
5. 用**检索**快速找到"上一次我写过的关于'柯西收敛准则'的笔记/题目/卡片"。

## 3. 功能需求（FR）

### 3.1 笔记管理（RQ-NOT）

| ID | 需求 | 优先级 |
| --- | --- | --- |
| RQ-NOT-01 | 创建/编辑/删除 Markdown 笔记，正文支持 LaTeX 公式 | P0 |
| RQ-NOT-02 | 笔记归属于一个学科（数学分析/高等代数），可打标签 | P0 |
| RQ-NOT-03 | 笔记可关联到多个知识点 | P0 |
| RQ-NOT-04 | 按学科/标签/知识点过滤与搜索笔记 | P0 |
| RQ-NOT-05 | 笔记列表/详情展示，正文公式渲染 | P0 |

### 3.2 题库与刷题（RQ-QUIZ）

| ID | 需求 | 优先级 |
| --- | --- | --- |
| RQ-QUIZ-01 | 录入题目（题干可能含公式）、答案、解析、学科、知识点、难度 | P0 |
| RQ-QUIZ-02 | 题目类型：主观题/客观题（单选/多选/判断） | P0 |
| RQ-QUIZ-03 | 按学科/知识点/难度筛选题目 | P0 |
| RQ-QUIZ-04 | 组卷刷题：从题目集合中随机抽 N 道顺序作答 | P0 |
| RQ-QUIZ-05 | 记录作答结果，答错的进入错题本 | P0 |
| RQ-QUIZ-06 | 错题本：查看、重做、移除 | P1 |

### 3.3 记忆卡片 / 间隔重复（RQ-SRS）

| ID | 需求 | 优先级 |
| --- | --- | --- |
| RQ-SRS-01 | 创建卡片（正面问题、背面答案，均支持公式），归属学科/知识点 | P0 |
| RQ-SRS-02 | 按间隔重复（SM-2 类算法）编排复习计划 | P0 |
| RQ-SRS-03 | 今日到期卡片：复习并打分（记得/模糊/忘记），更新复习计划 | P0 |
| RQ-SRS-04 | 卡片按学科/知识点/状态（待复习/新/熟）筛选 | P1 |

### 3.4 知识点图谱（RQ-KG）

| ID | 需求 | 优先级 |
| --- | --- | --- |
| RQ-KG-01 | 维护知识点（名称、学科、简介，含 LaTeX），可含子知识点 | P0 |
| RQ-KG-02 | 知识点间可建立**前置依赖**关系（A 是 B 的前置） | P0 |
| RQ-KG-03 | 以图形方式可视化知识点的依赖结构 | P1 |
| RQ-KG-04 | 点击知识点可查看其关联的笔记/题目/卡片 | P1 |

### 3.5 知识检索（RQ-SEARCH）

| ID | 需求 | 优先级 |
| --- | --- | --- |
| RQ-SEARCH-01 | 对笔记/题目/卡片/知识点的**标题与正文**做全文检索 | P0 |
| RQ-SEARCH-02 | 检索结果按类型分组，点击跳转到对应详情 | P0 |
| RQ-SEARCH-03 | 检索支持关键词高亮 | P1 |

### 3.6 通用需求

| ID | 需求 | 优先级 |
| --- | --- | --- |
| RQ-COMMON-01 | 学科管理：预置数学分析、高等代数|线性代数，可增删 | P1 |
| RQ-COMMON-02 | 所有富文本（笔记/题目/卡片）统一 KaTeX 渲染 | P0 |
| RQ-COMMON-03 | 数据可整体备份（SQLite 文件导出/下载） | P1 |

## 4. 非功能需求（NFR）

| ID | 需求 | 说明 |
| --- | --- | --- |
| NFR-01 性能 | 常见操作（列表/检索/单张卡片复习）响应 < 500ms（本机） | 
| NFR-02 可用性 | 单用户，界面简单直观，学习成本低 |
| NFR-03 可靠性 | 数据不丢失，写操作幂等，异常有清晰错误提示 |
| NFR-04 安全 | 单用户；访问其它设备时用基础鉴权（文档 03/04 定义）|
| NFR-05 可维护 | 前后端分离，代码/接口/文档编号可追溯 |
| NFR-06 可移植 | SQLite 单文件可拷贝迁移；本机开发、可部署到任意有 Python+Node 环境 |
| NFR-07 公式 | LaTeX 公式渲染准确（KaTeX），不支持标记时优雅降级为纯文本 |

## 5. 范围边界

**在本系统内**：笔记、题目、卡片、知识点、检索、复习调度。

**不在本系统内（明确不做）**：
- 多用户账号与权限管理（当前单用户；仅提供访问鉴权）。
- 自动批改主观题（仅记录用户自评对错）。
- 云端同步（用户自行通过部署/备份实现）。
- 内容自动生成（如 AI 出题）——如需可后续作为可选插件。

## 6. 验收准则（DoR）

系统上线（首版可用）需满足：
1. 五大功能均可创建/查看对应内容，数据持久化到 SQLite。
2. 公式在笔记/题目/卡片中正确渲染。
3. 间隔重复能正确计算今日到期卡片并更新复习计划。
4. 检索能返回跨类型结果并可跳转。
5. 后端提供全套 REST API，前端通过 API 完成全流程（不直连数据库）。
